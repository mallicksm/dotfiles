                       KITTY CHEATSHEET                       cs+/  to reopen

cs   = ctrl+shift   (kitty_mod)         csa  = ctrl+shift+alt
press q to close this overlay


CLIPBOARD ───────────────────────────────────────────────────────────────────
  cs+c              copy selection to clipboard
  csa+v             paste from clipboard           (cs+v is vsplit; see WINDOWS)
  csa+s             paste from PRIMARY selection   (cs+s is hsplit; see WINDOWS)
  shift+insert      paste from PRIMARY selection   (kitty default, kept)
  cs+o              pass selection to xdg-open

TABS ────────────────────────────────────────────────────────────────────────
  cs+left           previous tab    (pure tab nav, no window step)
  cs+right          next tab        (pure tab nav, no window step)
  cs+t              new tab
  cs+q              close tab (keyboard)
  middle-click      close any tab from the mouse (kitty built-in)
  cs+. / cs+,       move tab forward / backward
  csa+t             rename tab interactively (kitty overlay)
  $ kktabname [name]  rename current tab from shell (any window in the tab)
                    -r resets; no args = prompt; needs allow_remote_control yes
                    defined in ~/dotfiles/utils/bash_kitty.sh
  (cs+h / cs+l also reach adjacent tabs -- but only when no window neighbor;
   see WINDOWS below.)

WINDOWS  (splits inside one OS window) ──────────────────────────────────────
  cs+s              :sp  -- horizontal split (new window BELOW; divider --)
  cs+v              :vsp -- vertical split   (new window RIGHT; divider | )
  cs+enter          new window (layout-default placement; pre-vim-mapping)
  cs+w              close window
  cs+h / cs+l       focus window LEFT / RIGHT, falls through to prev/next tab
                    when there is no window neighbor in that direction
  cs+j / cs+k       focus window DOWN / UP (no tab fallthrough; mirrors nvim)
  cs+] / cs+[       focus next / previous window (layout order, not directional)
  cs+1 .. cs+9      focus window N
  cs+f / cs+b       move window forward / backward in layout
  cs+r              start interactive resize (arrows, then enter)
  cs+f7             visually pick window to focus
  cs+f8             visually pick window to swap with
  csa+l             cycle layouts (stack / tall / grid / ...)

SCROLLING & HISTORY ─────────────────────────────────────────────────────────
  cs+up / cs+k      scroll one line up
  cs+down / cs+j    scroll one line down
  cs+page_up        scroll one screen up
  cs+page_down      scroll one screen down
  cs+home / cs+end  jump to top / bottom of scrollback
  cs+z / cs+x       jump to previous / next shell prompt   (shell-int)
  csa+h             open scrollback buffer in pager (less; q to quit)
  cs+g              open last command's output in pager    (shell-int)

HINTS  (pick things off the screen with the keyboard) ──────────────────────
  cs+e              open URL under or near cursor
  cs+p, f           pick a file path -> insert at prompt
  cs+p, shift+f     pick a file path -> open with default app
  cs+p, l           pick a line -> insert
  cs+p, w           pick a word -> insert
  cs+p, h           pick a git-hash-shaped string -> insert
  cs+p, n           pick file:line -> open in $EDITOR at that line
  cs+p, y           pick an OSC-8 hyperlink

OS WINDOWS / FONT ───────────────────────────────────────────────────────────
  cs+n              new OS window
  cs++ / cs+=       bigger font
  cs+-              smaller font
  cs+0              reset font size                    (your remap)

OPACITY  (dynamic_background_opacity is now ON; default = 0.9) ─────────────
  cs+a, m / cs+a, l increase / decrease background opacity
  cs+a, 1 / cs+a, d force opaque / reset to config default

DECORATIONS  (visible cues, no keybindings -- just so you know what changed)
  active split      purple  (#bd93f9) 2pt border on the focused split
  inactive splits   slate   (#3a3c4e) border + text dimmed to 0.85 alpha
  bell border       pink    (#ff79c6) when an inactive window rings
  tab bar           hidden when only 1 tab; angled (>) powerline separators
                    each tab pinned to 20-cell width (no bouncing)
                    right side shows: cwd | host | HH:MM   (muted slate fg)
                    custom drawer: ~/dotfiles/initrc/kitty/tab_bar.py
  titlebar          shown (default) -- WM provides drag/close/min/max
  background        90% opaque + 20-radius blur (compositor-dependent on X11)
                    cs+a,d to reset, cs+a,1 for fully opaque

META  (your "i forgot" panic buttons) ───────────────────────────────────────
  cs+/    cs+f1     show this cheatsheet
  cs+f2             edit kitty.conf in $EDITOR
  cs+f5             reload kitty.conf (no restart)
  cs+f6             dump full active config to a window
  cs+f10            toggle maximised
  cs+f11            toggle fullscreen
  cs+escape         open kitty's remote-control shell (REPL)
  cs+u              unicode input by name (e.g. "snowman" -> snowman char)
  cs+delete         reset terminal


Tip:    `kitty +kitten show_key`  prints what kitty receives for any keypress.
