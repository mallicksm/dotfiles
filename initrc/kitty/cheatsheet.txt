                       KITTY CHEATSHEET                       cs+/  to reopen

cs = ctrl+shift   csa = ctrl+shift+alt   ca = ctrl+alt   (press q to close)


CLIPBOARD ───────────────────────────────────────────────────────────────────
  double-click / drag   selecting auto-copies to clipboard (copy_on_select)
  middle-click          paste clipboard (works in zellij / vim too)
  cmd+v  /  ca+v        paste clipboard from keyboard
  shift+insert / ca+s   paste PRIMARY selection (X11)
  cs+o                  pass selection to xdg-open

TABS ─────────────────────────────────────────────────────────────────────────
  cs+t                  new tab            cs+q         close tab
  cs+left / cs+right    prev / next tab    cs+. / cs+,  move tab fwd / back
  csa+t                 rename tab (overlay)
  kktabname [name]      rename tab from the shell (see kk<tab> below)

WINDOWS  (splits inside one OS window) ───────────────────────────────────────
  cs+s / cs+v           split horizontal (below) / vertical (right)
  cs+enter              new window         cs+w         close window
  cs+h / cs+l           focus left / right (falls through to prev/next tab)
  cs+j / cs+k           focus down / up    (no tab fallthrough; mirrors nvim)
  cs+[ / cs+]           focus prev / next window (layout order)
  cs+1 .. cs+9          focus window N
  cs+f                  zoom: fill layout / restore   (like zellij alt+f)
  csa+f / csa+b         move window fwd / back  (cs+b is disabled)
  cs+r                  interactive resize (arrows, enter)
  cs+f7 / cs+f8         visually pick window to focus / swap
  csa+l                 cycle layouts (stack / tall / fat / grid)

SCROLLING & HISTORY ─────────────────────────────────────────────────────────
  cs+up / cs+down       line up / down    cs+pgup / cs+pgdn   screen up / down
  cs+home / cs+end      top / bottom of scrollback
  cs+z / cs+x           prev / next shell prompt   (shell-integration)
  csa+h                 open scrollback in pager (less)
  cs+g                  last command output in pager

HINTS  (keyboard-pick things off screen) ────────────────────────────────────
  cs+e                  open URL under cursor
  cs+p then: f=path  shift+f=path→open  l=line  w=word  h=git-hash
             n=file:line→$EDITOR   y=OSC-8 link

FONT / OS WINDOWS ───────────────────────────────────────────────────────────
  cs++ / cs+-           bigger / smaller font    cs+0   reset font size
  cs+n                  new OS window

OPACITY  (default 0.9) ───────────────────────────────────────────────────────
  cs+a,m / cs+a,l       opacity up / down     cs+a,1 / cs+a,d   opaque / reset

META  ("i forgot" buttons) ──────────────────────────────────────────────────
  cs+/  cs+f1           show this cheatsheet       cs+f2   edit kitty.conf
  cs+f5                 reload kitty.conf          cs+f6   dump active config
  cs+f10 / cs+f11       toggle maximised / fullscreen
  cs+escape             remote-control shell (REPL)
  cs+u                  unicode input by name      cs+delete  reset terminal

kk<TAB>  (shell commands for kitty — type "kk" then TAB) ─────────────────────
  kktheme <name|fuzzy>  switch theme (fuzzy match); subcommands:
                          list      interactive picker w/ live preview
                          save      snapshot current theme as rollback target
                          original  restore snapshot    dracula  vanilla Dracula
  kktabname [name]      rename current tab   (-r reset;  no args = prompt)
  kkbroadcast <cmd>     run <cmd> in every OTHER kitty window in this tab
                          -a         all windows, all tabs
                          -t REGEX   only windows whose title matches REGEX
  (all three need allow_remote_control yes; see ~/dotfiles/utils/bash_kitty.sh)


Tip:  `kitten show_key`  prints what kitty receives for any keypress.
